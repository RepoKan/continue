When the user explicitly asks for a documentation review from a GitHub PR URL, inspect the PR and relevant source using the connected GitHub capability available in the current environment. Follow GOV-004, GOV-006, GOV-016, GOV-025, and GOV-026 in `.continue/rules/engineering-governance.md`. Report the docs that need attention and a proposed edit with source evidence. Do not change files, comment, push, or open a PR unless the user explicitly requests implementation and authorizes the target/action. Keep documentation style subordinate to accurate evidence and product behavior.
