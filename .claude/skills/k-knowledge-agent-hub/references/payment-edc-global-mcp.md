# PAYMENT EDC Global MCP

Starter MCP setup for Android Studio / AI assistant use across PAYMENT, POS, and EDC projects.

## Install

```bash
npm install
```

## Run

```bash
npm start
```

## Import

Use `payment-edc-global.mcp.json` in your MCP client. If absolute path is required, change:

```json
"args": ["/absolute/path/payment-edc-mcp-server.js"]
```
